# cocoex Brand Rules

Canonical. Apply silently. Never deviate without explicit instruction from MEMO.

---

## Name rules

- **`cocoex`** — always lowercase in copy. Never capitalised, never small caps, never all-caps.
- **`CoCoEX`** — graphic asset only. It exists as a logo file. Never typed in copy.

---

## Tone

Precise, poetic, never generic.

**Never use:** innovative, transformative, cutting-edge, leveraging, impactful — or any language that reads like it could be on any NGO website.

Reference world: independent publishing, art institutions, artist studios. Not SaaS, not tech, not corporate.

---

## Colour palette

| Role | Hex |
|---|---|
| Black | `#0d0d0d` |
| White | `#FFFFFF` |
| Off-white | `#f5f2ed` |

Gradients are decorative and atmospheric — hues follow the active Muse colour. Never structural.

Muse colours travel with their Muse. See [[The Seven Muses]].

---

## Typography

| Role | Font |
|---|---|
| Headers / body primary | Canela / Canela Deck |
| General substitute (Canela unavailable) | Playfair Display |
| PDF / ReportLab environments only | Lora (`/usr/share/fonts/truetype/google-fonts/`) |
| Labels, metadata, technical strings | Space Mono |

- **DM Serif** is a retired placeholder — never use it
- Display type is always serif
- Google Fonts loaded via `<link>` tags, never `@import`

---

## Visual identity principles

- **Ground modes:** black and white alternate for rhythm and contrast — no fixed rule
- **Gradient mode** at Muse/identity level only
- **Layout:** space is the separator. Elements float on open ground. Never put elements in boxes
- If it feels like a spreadsheet, it's wrong. If it feels like a small press monograph, it's right
- Large geometric shapes (black semicircle, white circle on black, black arc bleeding off-edge) are legitimate layout devices
- **Illustration system:** fixed library of hand-drawn illustrations — mushroom-cloud, sun with raised hand, brain/idea blob, reaching hand releasing a star, impact pot. Never substitute geometry or emoji
- **Dot trails:** sequences of progressively-sized dots. Use only when MEMO has established them in the active format

---

## Logo system

All three logos are hand-drawn by MEMO — one visual system, the same object from three vantages:

- **cocoex symbol** — helix vortex (yin-yang), front view
- **Comet Collab** — same symbol from the side + trajectory line
- **Muse** — the constellation from above; word intentionally near-illegible, revealing itself like eyes adjusting to the night sky

Never suggest simplifying or making the Muse logo more readable. Never use geometric placeholders to represent cocoex programmes. Individual Muse symbols to be provided by MEMO.

---

## Mission & throughlines (approved, final)

**Mission:** Art moves people. People move the world.

**Throughline:** The creation belongs to the artists. The impact belongs to the world.

Do not suggest alternatives unless MEMO asks.
